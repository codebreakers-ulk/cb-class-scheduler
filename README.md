# Class Scheduler

A weekly lecture and timetable planner for students to manage coursework sessions, lab hours, and room locations.

Built with **vanilla HTML, CSS, and JavaScript**. Data persists directly in the browser via `localStorage`.

---

## Getting Started Locally

No installation or external servers required.

1. Fork and clone this repository:
   ```bash
   git clone https://github.com/<your-username>/cb-class-scheduler.git
   cd cb-class-scheduler

    Open index.html in your web browser.
