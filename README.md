# Class Scheduler

A weekly lecture and timetable planner for students to manage coursework sessions, lab hours, and room locations.

Built with **vanilla HTML, CSS, and JavaScript**. Data persists directly in the browser via `localStorage`.

---

## Features

- **Add Class Sessions:** Create class entries with course name, instructor, day, time, and room details.
- **Weekly Timetable:** View the complete weekly schedule or select a specific day.
- **Class Details:** Check the instructor, timing, and room information for each session.
- **Remove Classes:** Delete sessions from the timetable when they are no longer needed.
- **Automatic Sorting:** Classes are arranged by their starting time.
- **Local Storage:** Schedules are saved in the browser using `localStorage`, so they remain available after refreshing the page.
- **Schedule Overview:** View the number of scheduled classes and an empty-state message when no classes are added.
